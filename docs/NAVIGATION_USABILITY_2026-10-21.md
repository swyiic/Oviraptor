# 1.1.68 导航与会话查找

## 使用变化

- 侧栏顶部固定为对话、资产、扫描。对话页只显示会话历史；业务页使用 80 px 窄栏，栏目移至内容顶部。
- 资产列表、隔离区、任务中心等直接从顶部进入。长页面滚动时，栏目仍固定在顶部；较窄窗口允许换行，移动断点使用栏目选择框。
- Skills 管理位于配置中心，原有技能库和对话内技能选择保留。旧 Skills 路由继续兼容。
- ⌘K / Ctrl+K 从任一普通页面进入当前工作空间的会话查找。按保存的完整标题检索，方向键选择、回车打开、Esc 关闭。
- 侧栏最多展示 20 条会话，当前选中的旧会话仍保留在列表中；完整列表从“全部”或快捷键访问。查找面板分批渲染结果，旧版会话接口继续支持加载更多。
- 切换模块保留聊天组件和未发送草稿；选择会话沿用既有读取路径，不发送消息、不恢复执行任务、不增加授权。

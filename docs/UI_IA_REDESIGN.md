# Oviraptor 导航/IA 重构方案（扫描 + 资产 + 配置）

> 目标（用户原话）：**用户少点击、少操作就能达到目的，不绕脑子。**
> 原则：以**任务/目标**组织,而不是按内部功能堆页；高价值信息**汇总到总览**;常用动作**就地可做**,不来回跳转;低频项收进「更多」。
> 分工：Opus 做跨模块**视觉统一**(卡片/字体/间距/明暗);本方案的**结构/路由/分组**由主会话(4.8)实现,用 Opus 的设计语言。
> 实现主要改:`src/plugins/hostCatalog.ts`(页面/标签定义)、`src/shell/moduleCatalog.ts`(装饰/徽标)、`src/features/*/workspace/*.vue`(section 路由与默认页)、以及把隐藏 section(行动中心/熔断区/新建)接回导航。**不删组件、不改数据/逻辑/i18n**,只改"有哪些入口、默认落哪、谁合并到谁"。

---

## 1. 扫描（Sentinel）— 已与用户确认方向

**现状**:执行概览 / 结果与证据 / 任务与成本 / 知识与策略 / 日志,外加**藏起来没入口**的 行动中心、熔断区、新建。要扫一个站:进扫描→找新建→填一堆→创建→跳执行概览→结果在别处→交 Agent 又跳。

**新**（以目标为中心,信息汇总）:
- **总览**（默认落地 = 找回的仪表盘/行动中心）：一页汇总 ——运行中的扫描(状态内联)、**高价值机会/发现**、**卡在熔断区待复核的目标(内联"清除/重扫")**、醒目「**+ 新建调查**」。
- **结果与证据**：某次扫描的详细结果/证据/接口图谱。
- **执行概览**：某次运行的实时明细(Agent/分支/预算);「交给 Agent」就在总览和这页,不再跳。
- **更多**（收起）：任务与成本、知识与策略、日志。
- **新建调查**：只填目标 URL(+可选模式),高级选项默认折叠;创建后**留在总览**就地看跑。

核心路径：`总览 →（填 URL）新建 → 就地看跑 → 就地交 Agent/看结果`。

---

## 2. 资产（Assets）— 10 页 → 5 组（待用户确认分组）

**现状(10)**：仪表盘 / 任务中心 / 资产 / 项目种子 / 归属门禁 / 公开暴露面 / 变化对比 / 隔离区 / 发现资产 / 资产日志。

**新(5,按"我要干嘛"归并)**：
- **总览**：资产概况 + 待办(待归属、待复核暴露、变化提醒)。
- **资产**：主资产列表;「发现资产」作为这页的 **+发现** 动作内联(不再单独一页)。
- **治理**：**归属门禁 + 公开暴露面** 合并(都是"这资产归不归我管、对外暴露了啥")。
- **变更**：**变化对比 + 隔离区** 合并(都是"有什么变了 / 什么被挡在外面")。
- **更多**（收起）：项目种子、任务中心、资产日志。

> 需你确认:发现资产内联到「资产」、归属+暴露合并、变化+隔离合并——哪个觉得不该合并说一声。

## 3. 配置（Settings）— 按"配什么"归并（待确认）

**现状(散)**：配置档案 / API 连接 / 模型连接 / 域设置 / 安全规则 / 资产规则 / 应用设置 / Worker 设置。

**新(4 组)**：
- **连接**：API 连接 + 模型连接(都是"接外部服务")。
- **规则**：安全规则 + 资产规则 + 域设置(都是"判定/门禁策略")。
- **配置档案**：profiles(保留,是上面这些的打包切换)。
- **应用与运行时**：应用设置 + Worker 设置。

## 4. 落地顺序
1. 等 Opus 跨模块视觉统一收尾(避免同文件冲突),确认其 `npm run build` 通过。
2. 主会话实现本 IA:改 `hostCatalog.ts` 页面/标签、`moduleCatalog.ts` 装饰、各 workspace 的 section 路由与默认页、接回隐藏 section、把合并项的子视图并入同页(用 tab/分段,不新开路由)。
3. 连同已就绪的 **web_executor 预算降级 + §1.9**(`docs/SESSION_HARDENING_STATUS.md`)一次性整合 `tauri build` + 装 App。
4. 用户验证:核心是"少点击"——总览一眼看全、熔断区能清除重扫、新建到看结果不跳来跳去。

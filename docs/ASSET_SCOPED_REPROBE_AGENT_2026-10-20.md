# 资产范围复测与自主探测 Agent（2026-10-20）

本轮范围：修复资产页复测忽略勾选/筛选范围的问题；新增根据线索持续规划与执行的 Agent；统一入口、按钮与运行反馈。不恢复此前暂停的整体 Agent 重构任务，不修改真实数据库或 CAS，不调整 VPN/Tailscale。

## 复测行为

- 勾选优先：仅传递勾选的项目/资产 ID，支持跨页勾选，拒绝混合项目、已删除资产和数量过期的请求。
- 无勾选：传递当前完整筛选条件，包含高级条件、人工结论、探测分类、登录/注册/已看状态、响应指纹等。复用生产列表的过滤器，不另写简化版 SQL。
- 筛选匹配全部分页和折叠组成员，数量显示为实际成员数；显示列只影响展示/导出，不影响探测范围。回收站不参与。
- 启动时在事务内解析并固定 ID，写入任务快照。恢复复用原输入文件，不因新资产入库扩大范围；非法范围快照报错，不降级为全项目。
- 仪表盘入口改为“筛选资产并复测”，先进入资产界面。保留旧 SDK/历史无范围任务的既有恢复契约。

## 自主探测

入口位于资产页和新建查询页的行内折叠面板，不新增浮窗。

执行链：固定系统指令 + 用户可编辑目标 + 当前项目确认的域名范围/线索/资产摘要 → 共享 Rust 模型网关 → 单步结构化决策 → 后端校验 → 现有原生工具 → 真实结果 → 下一轮规划。

支持读取资产、提取现存证书/页面/CNAME 线索、CT、DNS CNAME、可选 Hunter 精确补查、探测当前范围内已有资产、探测已实际发现的具体域名。对新域名仅建立 P3/0 分待核验候选；不自动确认归属。禁止模糊公司名大范围付费搜索、任意 IP 探测、猜测域名、扩展父域、把外部 CNAME 当成授权、恢复回收站资产。

每轮决策和结果持久保存；UI 展示规划轮数、资产预算、Hunter 请求次数、原生任务 ID、执行理由与回执。点击停止取消模型请求并请求原生任务停止；在途请求需退出后才结束。关闭应用后标记中断，不自动重放结果未知的操作。目标和策略固定，但模型选择可能因线索变化而不同；权限/范围/预算由后端硬约束，不依赖提示词。

默认 8 轮、100 条资产、15 分钟、Hunter 0 次。可设范围为 1–32 轮、1–1000 条、1–60 分钟、0–10 次 Hunter。模型每轮只请求一次，无自动模型重试；输出上限 1200 tokens。此处使用配置中心的统一模型连接与原生网关；不是往普通聊天插入一条消息，也不会启动旧 Worker 或 Tailscale。

## Hunter 消耗

- 默认关闭；明确填写大于 0 的请求上限才授权本轮调用。
- 自主模式每次最多请求 10 条，只查近 30 个日历日的第 1 页，禁止自动翻页/自动切换历史范围。
- 请求前读取账户信息。免费积分为 0、无法确认免费积分或不足最小分页时，不发送搜索，不自动改用权益积分。
- 同时受现有项目每日请求预算限制。失败/结果未知也占用本轮请求预算，不自动重试。
- 请求数不是积分数；实际消耗、余额以官方回执为准。UI 展示 consumeQuota / restQuota；缺少成功回执时显示消耗未确认。预检和请求之间的账户并发消费仍由服务端结算，不能承诺绝对零收费。

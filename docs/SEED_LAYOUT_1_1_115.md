# 项目种子布局修复 1.1.115

修复新增主体字段后来源及操作列被压缩的问题。表格八列使用显式 colgroup 宽度，来源标签及历史条数不拆行，详情与排除按钮并排显示。表格总宽不足时在列表内部横向滚动，保留日期、状态和完整操作入口；小窗口继续使用卡片排列。详情面板按列表容器位置固定停靠，外层滚动后保持可见，内容独立滚动；避免祖先滚动容器让 sticky 失效。主体及域名长值允许换行，证书完整值仍在详情中查看和复制。核验状态按钮显式设置背景，避免继承系统灰色按钮外观。

验证生产 Vue 组件及真实项目已保存快照在 1920、1440、1100、800、640 像素宽度下的布局，检查按钮尺寸、来源不拆行、页面不横向溢出及滚动后详情面板可见。快照渲染不代表原生 App 点击验收，测试不向目标站点、Hunter 或模型发请求。本次不修改种子归属规则、授权、任务或数据库，全量清洗保持暂停，VPN 不变。

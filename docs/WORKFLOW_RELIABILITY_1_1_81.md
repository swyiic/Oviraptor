# Oviraptor 1.1.81 任务与发现闭环

## 交付范围

此版本修复任务恢复、证据更新、范围一致性和 Host 卡顿，并让聊天与资产页使用同一个持久化 AI 发现任务。模型不能确认新增探测范围；用户一次确认域名家族后，已有免费补证队列接续 CT、DNS/CNAME 和 TLS，不自动调用 Hunter。

- 资产任务终态先写带 attempt 身份的本地回执；数据库暂不可写时显示「保存结果」，仅重试保存。重启恢复不会重新执行采集、探测、导入或付费请求。旧终态与其他活跃实例受到保护。
- 证书任务明确区分尚未执行的配置错误与执行结果未知。仅有可信同项目、同原始操作回执时解除对应旧阻塞，不重放未知请求。
- 新证书、备案与域名事实会更新现有证据组，旧证据版本、人工结论和原模型回执保留。增量更新继续遵守是否包含隔离记录的选择。
- 暂停通知与等待共用同一把互斥锁，消除通知发生在进入等待之前的丢失唤醒窗口；先提交暂停状态再唤醒，重复暂停不覆盖已退出的终态。23 条 Assist 回归以 8/16 线程交替运行 20 轮全部通过，另有旧代码失败、新代码通过的确定性负例。
- AI 继续优先复用同项目、同确认范围的可恢复持续补证队列，保留队列 ID、扫描游标、条目与尝试次数；正在暂停中的 owner 明确等待保存，不另建替代队列。范围已变更的旧任务不复活。
- TLS 对每个解析地址执行完整 TCP + TLS 尝试；SAN 优先，仅在没有 SAN 时使用有效 DNS CN。IP SAN 不会被 CN 反向覆盖。网络失败保留重试与退避，重试尚未结束不再显示任务完成。
- 资产镜像同步移至独立 SQLite Worker，相同请求合并，源和镜像版本未变化时直接复用；同数量修改、删除、范围变更、镜像外部写入和项目映射变化都会使缓存失效。
- 聊天、资产页共用 AI 发现 owner 与暂停、进度和集中确认入口。模型只获得有界摘要，完整候选留在人工确认面板；共享平台限定具体主机。新运行环境必须持有当前披露授权，旧授权不能通过伪造最新版本绕过。
- 范围建议先排除没有当前非回收本地见证的候选，避免历史人工接受项使整个确认批次失败；最终确认仍在同一事务重算建议、校验 token、范围与当前证据。每组混合域名判断只计算一次。
- 发现桥接保留单次较长等待窗口，不通过自动重发处理超时；未知结果继续对账。聊天确认载荷支持最多 500 项的实际上限，避免合法较大批次被旧 64 KiB HTTP 限制拒绝。
- 聊天纠正信息完整持久化并显示投递状态；工具失败保留经过脱敏的真实原因、阶段与操作号。模型实际用量持久化，未知用量不显示为零。
- 隔离区导航与列表共享同一计数口径；刷新等待实际读取结束。损坏的列设置降级为可用布局，不覆盖原设置、不导致白屏。

## 自动回归

`npm run test:ui` 自动发现所有 `tools/test_*.cjs`，`npm run test:agent-first` 覆盖 SDK、Host、应用与通道。新增 GitHub Actions 为 PR 和 main 执行同一流程，并运行原生资产、任务、证书和隔离计数回归。构建先生成域页面，再打包内置组件，防止旧生成物进入交付。

本机完整基线：UI 1,917 通过、8 项既有暂停功能跳过；Host/SDK/应用 947 通过、19 项平台或既有边界跳过；原生任务 224、资产 157、证书 6、隔离口径 1 项通过。后续真实规模发现的范围与桥接修复另有聚焦回归。跳过项不作为功能验收证据。

关键负例覆盖数据库写失败后恢复而 HTTP 采集次数仍为 1、旧 attempt 和其他实例不得覆盖、未知扣费不得重放、空范围不执行、项目切换晚回执、权限撤销、证据变化、共享租户不扩大、批量仅回收记录、镜像缓存竞态与停机释放。

## 真实项目证据

一致性备份中的中国移动项目包含 98,989 条关联资产，其中活跃 30,227、回收 68,762。28,099 条含测绘证书元数据；实际本地保存 DER 的只有 15 条、两张证书，活跃记录为 4 条、一张。15 条 DER 均能被 OpenSSL 解析，计算出的 SHA-256 与已保存值一致。元数据条数不能等同于完整证书或唯一指纹数量。

最新审阅共 12,478 组；其中 9,721 组暂存等待证据，主要是域名组和未绑定指纹的证书元数据。缺证不自动当成相关种子，也不要求逐条人工批准；只有新范围与真实冲突需要人工决定。

30,227 条真实资产备份在最终同步实现上的首读为 3,658 ms，后两次均小于 1 ms；同步期间 Host 心跳最大间隔 14 ms。该数据是离线真实项目副本的性能证据，不是窗口帧率或全产品性能验收。

真实规模的范围提案从 115 家族／212 项收敛到 109 家族／191 项，过滤 21 项仅历史或失效见证；逐项独立复核剩余无有效见证项为 0。相同 debug 只读测试从 19.33 秒降至 9.25 秒。范围确认保持事务校验，并对发现桥接使用 120 秒单次等待；不会自动重放结果未知的请求。

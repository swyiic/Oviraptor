# 1.1.88 聊天与执行流程

- 切换会话立即移除上一会话内容；失败与迟到响应不影响当前会话。
- 默认读取最新 50 条消息，可向前分页；正在读历史时不抢滚动位置，用“新消息”回到底部。
- 初始加载和状态恢复共用请求；回复结束后确保读取最终保存结果。重命名、置顶使用版本号避免旧响应覆盖；删除和重连同步会话列表。
- 文件列表按成功工具回执去重后分页，早期文件不再被最近重复写入挤掉。大文本预览和 Agent 文件读取均支持续读。
- 文件改写前后保存不可变快照，可在预览中切换历史版本。历史版本从本版本实际写入开始记录，不追造已丢失的旧内容。会话共用项目工作区，当前文件和历史快照分开显示。
- `workspace_run` 接通 Node.js/Python 脚本执行：复制工作区到独立目录，禁用网络和私人目录访问，返回退出码、输出、错误及生成文件。失败后可修改脚本并复测，成功的文本输出才写回工作区并记录版本。超时或撤回授权不发布输出，不自动重放未知请求。
- 完全放开模式包含隔离脚本执行；每次询问模式仍需独立执行授权。文件读写授权不会自动取得执行权限。
- 执行最多 60 秒，输入最多 1,000 个文件/20 MiB，单文件最多 1 MiB；输出文本单文件最多 256 KiB。删除不写回，不安装依赖；macOS 脚本不能再启动子进程，避免脱离超时或暂停控制。macOS 使用系统 sandbox-exec，Linux 需要可用的 bubblewrap，否则明确拒绝执行；不以普通子进程冒充隔离。
- `execution_success` 验收只认可本轮真实成功执行回执，表示该脚本退出零，不代表整个产品通过验收。
- 普通聊天里的资产发现面板按需展开。

本次不修改探测范围、Hunter 策略、VPN 或用户账户配置。

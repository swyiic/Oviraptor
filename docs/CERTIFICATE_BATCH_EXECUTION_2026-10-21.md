# 批量证书补采与 Agent 执行接口

## 行为

原生资产页、查询页和任务中心增加独立证书任务面板。任务在当前项目已确认域名范围内冻结缺少有效指纹的 HTTPS 资产快照；无手工 1000 条分页限制。面板显示创建时范围筛选、成功、失败、跳过、待处理、唯一指纹及新增指纹，支持任务历史、暂停、继续和显式重试失败项。

执行器只进行带 SNI 的 TLS 握手，不发送 HTTP 请求、跟随重定向、抓取页面或调用付费测绘服务。观察完整叶证书 DER 后解析并计算 SHA-256；既有完整 PEM/DER 可以直接使用。此流程采集证据，不断言证书 CA 信任、资产归属或扫描授权，也不修改已有 TLS 配置。

每个资产的证书字段、发现种子和队列结果在同一 SQLite 事务中提交，仅合并 `probe_cert_*` 字段，保留原来源、人工结论和页面探测结果。已完成项不随恢复重做，失去范围或被移除的资产跳过；显式重试仅重新排队失败项。暂停停止领取新项，允许在途握手保存结果；退出时的未保存握手在下次启动归入可恢复项，应用不会擅自自动恢复网络请求。

## 接口

Assets 内置组件更新为 1.2.0，增加：

- `certificate_task_start`：创建并开始；`startPaused` 仅建立暂停队列。
- `certificate_task_status`：当前项目最近任务或指定任务的持久进度。
- `certificate_task_pause`：停止领取新资产并保存当前握手。
- `certificate_task_resume`：继续未完成项；`retryFailed` 显式重试失败项。

查看使用现有 `inventory.read`，执行使用独立 `certificate.collect`。Host 按保存的项目外部绑定转换到桌面项目 ID；工具不接受模型提供的数据库路径、任意 URL 或项目覆盖参数。授权和版本在调用前后复核。受信任桌面启动器创建随机端口、本机回环、随机 bearer 的内部桥；凭证仅给 Host，不给模型或应用 worker，拒绝浏览器 Origin、无认证和不合约帧。

Agent 对明确证书任务操作使用上述业务工具，避免走通用任务计划/验收 DSL。控制操作返回后读取一次真实任务状态便回复，不在模型循环中等待整批任务结束；后台队列继续执行。

## 回归证据与交付边界

- 原生任务回归 11 项通过：5,004 项冻结快照及尾项、活动暂停后重开恢复、未重复已完成尝试、显式失败重试、来源字段保留、范围撤销/回收时拒绝写入、索引失败回滚、真实本地 TLS 握手无 HTTP 请求、相同证书多资产去重及内部桥认证。
- Host 531 通过、17 跳过、0 失败，包含真实 AppManager 权限/路由与提供商循环接口测试；不代表所有模型或生产任务均通过。
- 证书任务 SFC 3 项通过，覆盖共享任务身份、跨项目过期响应和归档禁用；Vue 类型与 Vite 构建通过。
- 实际安装、内置组件升级、真实项目网络读取、暂停和重新打开 App 后恢复的结果另行记录在本地私有交付报告，真实资产、配置和密钥不随源码上传。

完整产品、长期大规模网络性能及 Hunter 付费关联采集不属于上述本地回归结论。证书成功资产数与唯一指纹数应分别展示，多个主机共用一张证书时唯一指纹不会逐资产增加。

# 1.1.91 暴露面流程整理

内置 Assets 1.2.13。延续 1.1.90 的原生 Agent 通道，不改变模型授权类别、已确认范围、采集预算或历史结论。

## 操作流程

主入口仍是总览、采集任务、线索复核。已有数据可直接让 Agent 梳理；没有准入资产时，页面说明先在归属门禁确认并授权目标，不再允许从尚未读到范围或零准入的页面启动空任务。原生执行门禁仍独立校验。

后台轮询只更新汇总、任务和来源进度，不再把已加载多页的线索刷回第一页。有新结果时显示刷新提示，用户阅读位置保持不变。任务历史可以继续加载更早轮次，保留所选任务；导出在生成和读回核验期间显示进行中，并阻止重复点击。

证据面板打开新线索时先清空旧证据，关闭即撤销本次界面读取；迟到响应不会再次打开。待归并队列与证据读取使用独立请求序列及错误状态，刷新一边不会取消另一边。队列后续分页沿用原筛选，连续点击不会发两份请求。

复核表单随线索切换清空依据及整改说明，同项目操作者保留，切换项目清空操作者。读完并绑定当前线索的证据、复核轨迹及整改记录后才能提交；重新读取失败时不允许沿用半更新的快照写入。整改引用的观察与来源轮次保持一致。

单条线索的整改历史直接由原生 SQLite 按项目和 findingId 筛选，使用组合索引；不再逐页扫描整个项目。后续页的 total 始终是完整筛选总数。游标绑定项目、线索和状态，末页不附带下一页游标。旧接口调用方式仍兼容。不同历史读取可以并行；超过旧兼容读取窗口或游标不前进会明确报错，不当作“没有记录”。

事件详情、传播位置和合并目标分别有请求序号。切换事件后，旧操作的回执不会重新打开旧事件或改写新表单；后读的合并目标不会被先前慢响应覆盖。历史建议与任务恢复均有重复点击保护；跨项目及卸载后的响应不再发布到当前界面。

## 视觉

统一暴露面主要字段、操作和进度的可读字号；表单、证据和复核区域跟随应用主题，修正浅色界面中的深色输入框。摘要说明占整行，不再混进统计卡片网格。工具栏、筛选、操作按钮和卡片随可用宽度换行；覆盖矩阵保留可横向滚动的最小列宽。

## 验证边界

回归包含实际 Vue composable/SFC、原生临时 SQLite，以及完整 UI、Host 和 owner 检查。新增竞态用例先在旧实现失败，再验证修复。布局截图使用明确标记的合成数据；不能据此宣称真实来源覆盖或 AI 判定准确率。已安装 App 的真实项目检查、数据保留证明、最终检查结果和提交对应关系保存在本轮本地交付报告。

本次不启动 Hunter、不改变 VPN，不自动恢复隔离资产，不修改用户授权或人工结论。新索引不改变业务记录。

# 1.1.80 界面与刷新反馈

- 保留工作区顶部统一的「新建查询」，移除概览与任务中心内部通往同一页面的重复按钮。
- 隔离区导航展示当前项目全量数量，不再压缩成 999+；零值与窄窗口菜单一致显示。
- 原生界面与独立 Agent UI 的手动刷新显示实际请求进度，防止连续点击重复发起；完成后短暂提示，失败显示错误状态。快速请求保留短暂可见反馈，减少动态效果的系统设置仍生效。
- 刷新包装保留原处理函数和异常，不增加查询、模型或 Hunter 调用；吞掉异常的读取通过 owner 的错误状态判定，emit 控件使用 owner 的 busy 状态，没有可验证完成状态时仅提示已发起。
- TLS 卡片分开显示当前确认范围与历史任务范围，统计使用响应式网格，旧任务的 0 条进度不再表示当前范围无需补采。旧缺少选择统计的记录仍可查看。
- 新范围不会复用旧范围的暂停队列；旧记录保留，同范围与相同操作保持幂等，每项执行前继续核对当前范围。同项目只允许一条活动证书队列。

验证包括真实 Vue renderer 的事件包装、完成后的 disabled 同步、项目切换晚回执、错误反馈、卸载与重复点击；真实 SFC 与临时数据库覆盖任务范围复用及旧记录兼容。自动窗口工具未获准操作当前 App，窗口视觉验证与代码/DOM 测试分开报告。配置、数据及 VPN 不属于本次修改范围。

# 聊天导航与 Agent 调试记录

本次范围：左侧会话导航、输入框下方的模型与权限、真实模型协议兼容、只读查询与失败恢复。不是整套自主探测能力的最终验收。

## 已修改

- 左侧统一显示新对话、搜索、最近对话、删除入口；移除顶部重复会话下拉框及新增/删除按钮。模型与权限放到输入框下方。
- 权限面板区分当前会话文件权限与项目应用权限。查询结果按项目、会话及运行时身份隔离，过期异步响应不会串到新会话。
- 提供商侧工具名称使用合法、确定的别名，内部仍回到原始 MCP 名称并经过原有权限校验。DeepSeek 思考模式使用 auto 工具选择，续传私有 reasoning_content，不向 UI 发布。
- 单步项目读取仅提供适用的数据读取工具，避免模型把计数问题转成任务条件修改循环。当前追问优先于历史目标；目标归属/扫描许可字段不再被解释为需要重复授予库存读取权限。
- 相同工具和参数失败两次后停止第三次执行，并明确本轮缺口；允许换适用的读取工具恢复。

接口依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)及[Chat Completion 契约](https://api-docs.deepseek.com/api/create-chat-completion/)。修改前实际请求出现工具名称非法与 thinking/tool_choice 冲突两个 HTTP 400；修改后本轮场景均收到 HTTP 200。

## 后续验证

已验证的是上述有限场景。复杂多步自主任务、真实数万资产的长时间性能、全部提供商、Hunter 线上采集与额度扣费并未在本轮验收；本轮未调用 Hunter，不消耗其积分。模型回复仍存在冗长和内部字段过多的问题，提示改进不能保证每次措辞一致。

旧 Host 中已安装的 Assets 应用不会被覆盖式改写。如果仍为旧版，应在配置中心更新内置组件；版本或运行时身份变化需要一次新的对应授权，之后同一范围应复用，不应每轮重复请求。

Goal 已建立，用于继续对实际失败复现、修复及回归，后续应扩展到明确的多步任务，而不能把本次计数场景视为全部 Agent 能力达标。

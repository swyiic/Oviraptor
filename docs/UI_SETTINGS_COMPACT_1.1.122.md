# 配置中心紧凑布局（1.1.122）

根据收到的4张截图调整指纹库、Skills管理和资产API页面。用户提到的第5张截图未随消息收到，没有推测其页面。

## 页面行为

- 指纹库：统一搜索、来源和操作控件；总数/来源统计同行；规则使用紧凑列表，展开后仍提供完整ID、特征和AND/OR条件树。规则说明、路径与独立暴露检查放入折叠区。
- Skills：每个技能包一个汇总入口，Compound Engineering默认折叠其36个成员。展开、搜索、逐项启用和资源读取继续使用原技能ID；没有修改技能库数据模型。
- 长内容：列表描述最多两行，完整说明在资源详情中读取；来源、完整版本标识和能力说明按需展开。窄窗口选中技能后定位资源面板。
- 账户设置：FOFA与Hunter共用对齐的字段、密码显示控件与操作区。兼容来源及长诊断说明默认折叠，费用提示与错误状态保持可见，移除确认保留。
- 配置页面容器使用一致边距，分类保存按钮集中排列。

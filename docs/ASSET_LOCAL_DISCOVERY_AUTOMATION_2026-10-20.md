# 本地全量线索提取、证书核对与 UI（Fix11，2026-10-20）

## 当前交付

- “一键提取全部资产”代替每 1000 条人工点击。Rust 原生后台线程分批处理每批 200 条，批间让出时间；不启动外部 Worker、Tailscale、命令行工具或网络请求。
- 启动时冻结当前项目有效资产关联的 ID 快照。进度、游标、提取结果在同一事务提交；暂停保存进度，重启后可继续；失败批次回滚。其他项目和已移除资产不会被提取。快照之后的新关联进入下次显式提取。
- 只增加提取索引和进度数据，不更改资产的人工结论、归属、存活状态或原始文件。完成后回收本任务临时 ID 队列，保留完成回执。显式重提取新增线索去重，不能把已存在的线索再次统计为新增。
- 输入域名自动核对本地直接资产与已提取的证书域名 / 指纹线索，先返回已存在记录的提醒、资产 ID 和可复用指纹。精确证书域名可以找到本地 IP 资产，不要求 IP 属于某个 ASN。通配证书只匹配一层 DNS 标签，明确标为证书覆盖线索，不当作主机已发现。
- 原始记录含证书内容或证书域名而没有 SHA-256 时，明确提示缺少可用指纹；不从任意文本编造指纹，不把域名替代为指纹。补充识别已保存结构化证书 JSON 中明确的 SHA-256、CN 与 DNS 名称字段；不宣称可以解析任意证书文本或恢复历史未采集的数据。
- 本地证书域名关系依赖提取索引。未完成提取时提醒可能遗漏 IP 资产中的证书名称；已完成则展示索引更新时间，后续新入库资产可重新提取。输入检查只读，不自动请求 TLS / CT / DNS / Hunter，不消耗积分。
- 本地核对预览最多检查 200 条匹配资产，显示匹配总量及截断提示，最多展示 20 个不同指纹与 10 条资产依据；不能将预览当成唯一或全量结论。完整线索库支持服务端搜索、分类与每页 50 条翻页，不再只显示最近 200 条。
- 页面分为范围、后台提取、精确补查和线索库；本地操作与付费 Hunter 操作分开。长说明折叠，提取显示总数 / 已处理 / 新增线索 / 含证书信息 / 跳过数，支持暂停继续。已确认范围不被搜索或刷新覆盖掉未保存的草稿。
- Hunter 精确关联准入、近 30 天自动分页、逐页积分回执保持原有行为。VPN 设置未修改；本轮不进行带 Key 的真实 Hunter 查询，也不启动正常数据目录的 App。

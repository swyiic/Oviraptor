源码结果页现在使用与任务证据页相同的正式裁决读取组件，并可以按任务的实际执行轮次重新核验、分页查看和导出全部确认发现。历史分析器记录、人工标记、原仓库概况与旧 CI 汇总保留在独立折叠区，不冒充当前轮次的独立 Reviewer 结论。

新增独立审查 JSON 报告，不是把原项目包悄悄换成新格式。原项目包仍保留历史资料用途；它还没有统一携带本报告的正式裁决快照。SARIF 导出与回读、其他 Findings 消费方和总体覆盖独立审查仍未交付。本次不代表整个 Master Plan 完成。

## 正式读取与导出

- `native_source_findings_snapshot` 统一完成一次完整集合读取和审计，原分页接口在此结果上切片。保留任务/轮次、唯一根、Coordinator 原绑定、冻结材料、四阶段、Reviewer 回执、ACK 与精确裁决集合的核验。
- 新 Tauri 命令 `export_native_source_findings(scan_id, attempt_number)` 在 blocking worker 中打开数据库并重新核验完整集合；不接收 UI 传来的发现、状态、路径或审查证明。
- 页面只加载第一页也可导出全部确认发现；后续页中的证据损坏会拒绝整个导出。未交付、旧合同、歧义根、已删除任务或不存在的轮次均不能产生成功报告。
- 已核验零确认与未核验分别处理：前者可导出真实零确认快照，后者拒绝，不生成一个看似安全的空报告。
- 输出格式 `oviraptor-source-review-v1`，标记 `qualification: verified_at_export`、`executionEligible: false`、`coverageReviewCompleted: false`，保留审查范围、确认发现与来源引用。报告不是可迁移的执行许可或 Reviewer 原始凭证。
- 使用同一读取路径的人类可读字段脱敏；不附加原始模型应答、源码全文、执行凭据。保持不透明来源 ID。
- 文件名由 UUID 生成，绝不拼接用户的 scan ID；使用独占创建，不覆盖历史报告。写入并同步成功才返回路径，已知写入失败只清理本次新建文件。尚未宣称进程强杀下的原子文件发布/残留清理已验证。
- 历史租约到期可以导出原有可核验证据，但不会续租、修改账本、恢复任务或改变生产门禁。输出仅代表导出时的核验结果。
- JSON 报告与旧项目/任务导入格式不同；不提供伪装成 Native confirmed 的 JSON 回灌路径。本次没有完成报告往返导入功能。

## 页面接线与隔离

`SourceReviewEvidence.vue` 在任务证据页和 `SentinelSourceResults.vue` 中共用。

- 源码结果页只选择 `scanId` 精确匹配的实际轮次，过滤无效轮次并去重；不依据旧 `attemptCount` 凭空构造一个可审查轮次。
- 切任务、切轮次、重读时清除旧确认结果和导出路径，旧请求的成功或失败不能覆盖新范围。
- 导出按钮只在当前核验成功时出现；请求只携带 scan/attempt，不携带分页缓存。重复点击不产生并发请求。
- 后端导出核验或写入失败时撤销页面已有确认展示，要求重新核验；不暴露后端原始错误。迟到的旧任务导出不会在新任务页面显示路径或错误。
- 界面清楚标记总体覆盖未完成，导出也不代表 CI 已通过。
- 历史区保留原有人工验证操作，但明确说明人工标记不等于当前 Native 独立审查，旧门禁字段也不是当前轮次门禁凭据。

## 实际发现的父页面竞态

检查真实 `SentinelBoard.vue` 发现旧实现会直接把异步返回数组写入共享详情状态，没有核对请求发起时的任务或读取代次。

两个新增测试先复现失败：

1. A 的读取等待中切到 B，B 已加载完成后 A 返回，B 标题下的发现与轮次被 A 覆盖。
2. 新任务加载时旧内容未清空；旧请求的异常和 finally 可以污染新任务通知及加载状态。

红测日志：`/tmp/oviraptor-source-board-race-red.log`，4 通过 / 2 失败。修复后初次补测仍有一项失败：测试夹具只提供 `scanId`、漏掉真实 Finding 必有的 `kind`，旧生产筛选逻辑因而提前异常。补齐夹具字段，未放宽生产审查或删除断言。

修复包括：

- 手动打开和后台详情刷新使用读取代次与任务归属，整体收齐 checkpoints、findings、validations、历史比较、opportunities、attempts 与 AppSec 后再发布；过期响应不发布。
- 切任务、重新打开、移除选中项及卸载时清除详情状态并使在途请求失效；旧 finally 不改变新任务加载状态。
- 运行轨迹及调查图谱有独立读取代次；离开再回到同一个任务，也不能接受离开之前的迟到响应。
- 旧范围的执行/图谱读取请求不能清空当前范围，后台轮询不抢占进行中的人工详情加载。

这不是对整个 Board 所有异步操作的无遗漏证明；本次验证范围是上述任务详情、相关轨迹，以及新源码审查消费者。

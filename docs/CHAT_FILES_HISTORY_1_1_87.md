# 聊天时间、会话管理与文件

- 每条已保存消息显示发送时间；悬停查看含秒和时区的完整时间。
- 左侧会话支持右键或省略号菜单：重命名、置顶/取消置顶、在 Finder 中显示工作区、删除对话。置顶与标题保存后重启仍保留。
- 会话列表按置顶、最近活动排序；超过侧栏数量可用搜索查找。
- Agent 成功写入工作区的文件自动出现在“本会话文件”，点击名称可预览文本；回复中指向真实文件的 Markdown 链接也能点击。
- 预览显示实际路径，支持复制路径、Finder 定位；支持的文档或图片可用默认应用打开。代码、HTML 与脚本在界面内按纯文本预览。
- 文件按实际工具写入记录关联，不把模型声称的路径或普通代码块当成已经生成的文件。

当前项目的聊天共用 `agent-host/workspaces/<Host 项目编号>/agent` 工作目录。文件卡片关联本会话的写入记录，预览读取当前文件；其他会话或外部软件可能修改同一路径，此处不是生成时的历史快照。删除对话保留工作区文件。

读取文件列表不会创建目录。首次点击 Finder 时，若尚无工作目录，会创建此项目的固定空目录。文件已删除、符号链接或不属于可访问目录时会明确提示，保留历史记录。

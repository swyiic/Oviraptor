# 统一模型目录与 UI · 1.1.125

日期：2026-10-30。代码目录：`/Users/swyiic/Desktop/Rust/Oviraptor`。

## 使用变化

- 模型连接统一用于聊天、资产任务和 Nest。移除“仅聊天”“扫描默认”等用途开关，仅保留一个“设为默认模型”。添加非默认连接保留当前模型和其他连接。
- Grok OAuth 与 API、本地模型进入同一目录。登录只保存认证，不会悄悄替换当前默认模型；明确设为默认后同步聊天和任务侧选择。
- 已有任务保留原先的模型配置。现有界面没有新增每任务模型选择器，在模型目录设为默认后供后续对话、任务使用。
- 显示“已同步 / 待同步”。保存成功但 Host 同步失败时，保留连接，可重试同步而不重复创建。
- 编辑卡恢复内边距，统一 38px 输入框、36px 按钮和 16px 卡片间距；凭据与网络折叠展示，长名称换行，窄屏自动单列。

## 实际调用路径

OAuth 配置仅保存认证类型、模型名称与固定 xAI 地址；登录令牌仍由本机 Host 保存和刷新。原生任务通过受会话认证的本机桥调用共享 OAuth 登录，支持普通 JSON、流式 SSE、工具调用和取消；桥请求不经过扫描代理，不跟随重定向，也不会回退借用另一 API Key。

资产与 Nest 继续使用共享模型解析器；补齐了学习调用、旧对话地址校验和模型预检的 OAuth 路径。已保存的 API 目录连接保留明确的 URL 与模型 ID，不再根据 Grok / DeepSeek 名称猜测、重定向端点。模型 ID 的 `openai/` 前缀只在后端规范化一次，存取不会反复剥除。

旧配置保持兼容，无破坏性数据库迁移。OAuth 记录使用现有不可变目录描述符，不新增或伪造 API 凭据记录。真实数据库、CAS、用户登录和缓存均未操作。

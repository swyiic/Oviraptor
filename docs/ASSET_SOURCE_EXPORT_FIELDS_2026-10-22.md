# 资产来源与导出状态（1.1.71）

资产列表默认显示「资产来源」与「是否已导出」，保留旧的字段顺序与宽度。已有自定义列只迁移一次；之后取消的列不会反复强加回来。来源统一读取采集提供商与 discovery_sources_json 的实际来源回执，FOFA 与 Hunter 可同时显示；无法追溯的旧数据标为「历史记录 · 来源未记录」，不会从域名、证书或标题猜测来源。来源并不等于归属或有效性确认。

高级查询支持来源包含/排除以及已导出/无记录筛选，可选显示最近导出时间、导出次数，并可排序。导出状态按工作空间的资产关联独立保存；复采或探测不会覆盖。旧版导出没有逐资产记录，无法追溯，显示「未导出（无记录）」，不代表历史上绝未导出。

CSV 写出并同步文件后，以事务更新此次实际写出的精确资产集合；不重新执行可能已经变化的查询来标记。文件或数据库失败会回滚记录并移除此未完成导出文件。CSV 中的导出状态包含本次导出。折叠组保留各 URL；不同导出状态/次数/时间的资产不会折在一条状态里。

“已导出”表示本机已经成功生成并登记导出文件，不保证浏览器取回后保存到用户指定的目录。用户数据仅增添 project_assets.last_exported_at、export_count 字段；旧布局的四字段快照兼容读取，不在读时重写。内置资产组件和桌面入口同步更新。

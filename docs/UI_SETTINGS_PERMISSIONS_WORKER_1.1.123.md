# 数据权限与 Worker 界面（1.1.123）

延续 1.1.122 的配置中心样式，调整这次截图中的数据权限和 Worker 页面。现有源码改动保留，没有自动提交。

## 界面调整

- 数据权限：工作区与接收方对齐，权限模式采用统一控件；授权项按应用分组，显示已选数量、操作类型及权限 ID。长说明提供两行摘要与完整展开内容，关键授权确认始终可见。
- Worker：本机设置、节点表单与远程列表采用一致边距、38px 输入框和 36px 按钮；节点检测、同步和移除操作统一排列，错误完整换行。连接及环境说明收在可展开区域。
- 共享权限模式组件保留聊天 compact 布局；两页支持明暗主题和窄窗口。
